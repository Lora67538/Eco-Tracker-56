# Eco-Tracker 五看三定分析

本文基于华为「五看三定」战略方法论，对 Eco-Tracker 项目进行分析。

## 五看

### 看行业 / 趋势

「双碳」目标推动下，绿色低碳正在从口号走向日常。碳普惠、个人碳账本、绿色出行等概念逐渐普及，环保不再只是企业责任，也成为一种生活方式。轻量的个人碳足迹记录工具顺应这一趋势。

### 看市场 / 客户

目标用户是愿意为环保行动的学生、年轻上班族与环保爱好者。他们需要一个简单、无压力的打卡入口，记录自己「做了什么」，并获得正向反馈。用户核心诉求是低门槛、易坚持、看得见积累。

### 看竞争

同类产品包括蚂蚁森林、Keep 打卡、各类习惯养成 App。它们功能丰富但往往较重，或带有社交、积分等复杂机制。Eco-Tracker 的差异化在于「轻量 + 本地数据 + 开源」。

### 看自己

作为一个小型开源项目，优势是灵活、透明、易上手；不足是功能相对单一、缺乏运营与用户基础。因此更适合作为教学示例、个人工具或开源社区共建项目，而非追求规模化商业竞争。

### 看机会

机会点包括：开源社区共建、校园环保活动、个人碳账本接入、与碳积分/公益组织联动等。通过开源降低共建门槛，有机会形成小而美的生态。

## 三定

### 定战略控制点

核心控制点是「简单易用的打卡体验 + 本地数据隐私 + 开源可扩展」。其中，本地存储保证用户隐私，开源许可证降低协作成本，这两点是项目长期存续的关键。

### 定目标

- 短期目标：帮助个人用户养成低碳打卡习惯。
- 中期目标：在开源社区与校园场景中获得使用与共建。
- 长期目标：成为个人碳账本的轻量入口，支持数据导入导出与生态集成。

### 定策略

1. 用纯前端降低使用与部署门槛。
2. 通过 MIT 开源与清晰文档吸引贡献者。
3. 数据本地化，尊重用户隐私。
4. 以教育、公益、校园活动为切入点传播。
