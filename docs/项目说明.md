# Eco-Tracker 项目说明

## 项目简介

Eco-Tracker 是一个绿色低碳打卡小项目。用户每天选择自己完成的环保行为（步行、骑行、公交、自带杯、素食、随手关灯等），系统自动换算成减碳量并累积统计，帮助使用者养成低碳生活的小习惯。

项目定位为「简单、轻量、隐私友好」的个人碳足迹记录工具，采用纯前端实现，不依赖任何后端服务。

## 技术栈

- HTML + CSS + JavaScript（原生，无构建工具）
- `localStorage` 本地数据存储

选择纯前端的原因：降低使用门槛，任何人打开浏览器即可体验；同时方便开源社区直接参与和二次开发。

## 功能清单

1. 低碳行为打卡，支持一次多选。
2. 累计减碳量、连续打卡天数、本月打卡次数统计。
3. 每周减碳目标进度环。
4. 最近 14 天打卡日历。
5. 打卡历史记录列表。
6. 数据一键导出为 JSON 文件。

## 使用方法

```bash
# 直接打开
open index.html

# 或启动静态服务器
python3 -m http.server 8000
```

浏览器访问页面后，勾选今日完成的低碳行为，点击「完成打卡」即可记录。

## 数据模型

打卡记录以日期为键存储在 `localStorage` 中，结构如下：

```json
{
  "2026-11-13": {
    "date": "2026-11-13",
    "actions": ["walk", "bike"],
    "co2": 300
  }
}
```

其中 `actions` 为行为 id 列表，`co2` 为当天累计减碳量（克）。

## 分支管理

项目采用 Git Flow 的简化版本进行分支管理：

- `main`：稳定主分支，用于发布。
- `feature/ui`：页面样式。
- `feature/checkin`：打卡逻辑。
- `feature/stats`：统计与历史。
- `docs`：文档。

功能分支开发完成后，合并回 `main` 并保留合并提交记录，便于追溯。
