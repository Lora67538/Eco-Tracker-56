# Eco-Tracker · 绿色低碳打卡

一个简单、无后端依赖的绿色低碳打卡小项目。选择你每天的环保行为，记录并累积自己的减碳量，用每一次小小的行动守护地球。

## 功能特性

- 每日低碳打卡：步行、骑行、公交、地铁、自带杯、素食、随手关灯、垃圾分类等行为，自动换算减碳量。
- 连续打卡天数（Streak）与累计减碳统计。
- 每周减排目标进度条。
- 最近 14 天打卡日历与历史记录。
- 数据本地存储（`localStorage`），可一键导出为 JSON。

## 快速开始

这是一个纯静态前端项目，无需安装依赖，直接用浏览器打开 `index.html` 即可使用。

```bash
# 方式一：直接双击 index.html
open index.html

# 方式二：用任意静态服务器
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。
